# Marklet for Windows — 릴리즈 노트

새 버전은 **맨 위**에 추가한다(최신이 먼저). 각 버전 절은 아래 틀을 따른다.
GitHub 릴리즈 본문에는 해당 버전 절을 그대로 붙여 넣는다.

```
## 1.0.x — YYYY-MM-DD
한 줄 요약.

**새로운 것** / **바뀐 것** / **고친 것** — 해당하는 것만
- 사용자 눈에 보이는 변화 위주. 단축키는 `백틱`으로.

**설치**: `Marklet-Setup.exe` — 관리자 권한 불필요, 이전 버전 위에 덮어 설치.
SHA-256: `…`   (sha256sum Marklet-Setup.exe)
```

공통 안내(코드 서명 없음 · SmartScreen)는 맨 아래 한 번만 적는다.

**릴리즈에 올리는 파일 이름은 항상 `Marklet-Setup.exe`** (버전 번호 없음). README 의 다운로드 버튼이
`releases/latest/download/Marklet-Setup.exe` 를 가리키므로, 이름이 바뀌면 버튼이 깨진다.
(1.0.12 이하의 파일은 `Marklet-Setup-<버전>.exe` 였다.) Tauri 는 설치 파일을 `Marklet_<버전>_x64-setup.exe` 로 만든다 —
`npm run dist` 로 만든 뒤 올릴 때 이름을 `Marklet-Setup.exe` 로 바꾼다. SHA-256 은 **올리는 그 파일**로 잰다(다시 빌드하면 값이 달라진다).

## 1.1.1 — 2026-10-08
우클릭 · 더 보기(⋮) 메뉴가 1.0.12 의 Marklet 모양으로 돌아왔고, 네트워크 공유에 있는 문서의 그림이 뜬다.

**바뀐 것**
- 내장 뷰어(읽기만 하는 문서를 그리는 기본 화면)의 우클릭 · 더 보기(⋮) 메뉴를 Windows 기본 메뉴 대신 Marklet 의 드롭다운으로 되돌렸다 — 둥근 모서리, 반전색 강조, 항목마다 흐린 단축키. 1.1.0 에서는 이 모양이 WebView2 로 그린 문서(수식 · 편집 등)에만 남아 있었다.
- 메뉴는 `↑` `↓` `Home` `End` 로 이동하고 `Enter` 로 고르고 `Esc` 로 닫는다. 메뉴 밖을 누르면 메뉴만 닫힌다(그 클릭이 아래 링크를 열지 않는다).
- 제목이 없는 문서에서는 메뉴의 '목차'가 흐리게 보인다(전에는 눌러도 아무 일이 없었다).

**고친 것**
- 네트워크 공유(`\\서버\공유\폴더`)에 있는 문서를 WebView2 로 그릴 때(수식 · Mermaid · 편집 · 인쇄) 같은 폴더의 그림이 뜨지 않던 것. 문서가 다른 서버를 가리키는 그림은 전처럼 열지 않는다.
- 폴더 이름에 `#` · `%` · `?` 가 들어 있으면 WebView2 로 그리는 문서에서 그 폴더의 그림이 뜨지 않던 것.

**알려진 것**
- 내장 뷰어의 메뉴는 열릴 때 부드럽게 떠오르는 움직임이 없다(WebView2 로 그린 문서의 메뉴에는 있다).

**설치**: `Marklet-Setup.exe` — 관리자 권한 불필요. 1.1.0 위에 덮어 설치한다(1.0.12 이하에서 옮겨 올 때는 [1.1.0 릴리즈](https://github.com/bellx3/marklet/releases/tag/desktop-v1.1.0)의 "옮겨 올 때"를 먼저 본다). WebView2 런타임이 없는 PC 에서는 설치 프로그램이 Microsoft 에서 받아 먼저 설치한다.
SHA-256: `6c1e565949eed19532b86d157cf5d3868cd8c031b12eb77b70652a02843bc40c`

## 1.1.0 — 2026-10-08
Rust 로 다시 만들었다. 화면과 단축키는 그대로이고, 설치 파일이 100 MB 에서 4 MB 로, 첫 글자가 뜨는 시간이 0.5초에서 0.13초로 줄었다.
보안 · 개인정보 수정도 함께 들어 있다. 1.0.12 이하를 쓰고 있다면 옮겨 오길 권한다 — **새 판을 깔기 전에 예전 판부터 제거해야 한다**(아래 "옮겨 올 때").
(Electron 으로 만들던 1.0.13 은 배포하지 않았다. 그 수정이 이 판에 합쳐져 있다.)

**바뀐 것 (엔진)**
- Electron 대신 **Rust(Tauri)** 와 Windows 에 있는 Edge 엔진(WebView2)으로 바뀌었다. 설치 파일은 99.8 MiB → 4 MiB.
- **내장 뷰어를 더했다.** 글 · 표 · 목록 · 코드 · 그림만 든 문서는 Edge 엔진을 띄우지 않고 Marklet 이 직접 그린다. 이 PC 에서 첫 글자가 약 0.5초 → 0.13초, 메모리가 약 345MB → 50MB 다.
  수식 · Mermaid · SVG 그림 · 800KB 넘는 문서 · 편집 · 인쇄 · PDF 는 전처럼 WebView2 가 그린다(그 사이에도 내장 뷰어가 글을 먼저 보여 준다).
- **빠른 시작.** WebView2 로 그린 문서를 닫으면 5분 동안 창 없이 남아 다음 문서를 바로 연다(보기 메뉴에서 끈다). 로그인할 때 창 없이 미리 켜 두는 항목(기본 꺼짐)도 있다.
- 보기 메뉴에 **빠른 보기** · **닫은 뒤에도 잠시 준비해 두기** · **로그인할 때 미리 켜 두기** 가 생겼다. `Ctrl+Q` 로 열려 있는 창을 모두 닫고 끝낸다.
- 탐색기에서 `.txt` 가 `.md` 와 다른 아이콘(파란 바탕의 `TXT`)으로 보인다.
- 예전 판의 설정(테마 · 확대 · 최근 문서 · 창 크기)을 처음 실행할 때 이어받는다.
- 인쇄 미리보기는 Windows 의 Edge 인쇄 창을 쓴다. PDF 저장은 전과 같이 문서 이름으로 채워지고 책갈피가 들어간다.

**고친 것 (보안 · 개인정보)**
- 문서 안 링크가 네트워크 경로(`//서버/공유/문서.md`, `\\서버\공유\문서.md`)를 가리키면, 누르는 것만으로 Windows 가 그 서버에 연결(SMB 인증)을 시도할 수 있었다. 이제 이런 링크는 열지 않는다. 같은 공유 폴더 안의 문서끼리 거는 링크는 그대로 열린다.
- `//호스트/그림.png` 꼴의 그림 주소가 '원격 이미지 기본 차단'을 거치지 않고 통과하던 것을 막았다.
- Edge 엔진이 시작할 때 보내려는 백그라운드 요청(설정 서비스 · DNS-over-HTTPS 점검 등)을 막았다. 문서를 열고 읽는 동안 외부 서버로 나가는 요청이 없다(원격 이미지를 직접 켜거나 누른 경우만 예외). 내장 뷰어는 네트워크를 쓰지 않는다.

**바뀐 것**
- 인쇄 · PDF 에서 다이어그램 아래의 "탭하면 크게 보기" 안내가 빠진다. 화면의 안내는 "클릭하면 크게 보기"로 바꿨다.
- 도움말 → **오픈소스 라이선스** 를 더했다. 설치 폴더에도 같은 고지문이 들어간다(`THIRD_PARTY_NOTICES.txt`). Rust 크레이트 267개의 고지가 이번 판부터 들어 있다.
- 설치 파일 이름이 `Marklet-Setup.exe` 로 바뀌었다(버전 번호 없음). 다운로드 링크가 항상 최신 버전을 가리키게 하려는 것이다.

**알려진 것**
- 내장 뷰어는 스크린 리더(UI Automation)에 아직 대응하지 않는다. 스크린 리더가 켜져 있으면 모든 문서를 WebView2 로 그린다.
- 내장 뷰어의 코드 색은 12개 언어(JS · TS · Python · Java · Kotlin · Bash · JSON · YAML · XML/HTML · SQL · CSS · Markdown)에만 입힌다. 그 밖의 언어는 색 없이 보인다. WebView2 로 그린 문서는 전과 같다.
- 내장 뷰어에서 아주 넓은 표는 가로로 스크롤하지 않고 글자 단위로 줄이 바뀐다.
- 인쇄 미리보기는 Edge 의 인쇄 창이라, 1.0.12 의 쪽 썸네일이 있는 미리보기 창은 없다.

**옮겨 올 때**
1.0.12 이하의 설치본은 새 판과 폴더가 달라 따로 남는다. 새 판을 설치하기 **전에** 예전 판을 Windows 설정 → 앱에서 제거한다.
예전 판의 제거 프로그램은 `.md` · `.txt` 연결 항목을 같이 지우기 때문에, 새 판을 깐 뒤에 지우면 새 판의 연결이 풀린다(풀렸다면 새 판을 다시 설치한다).

**설치**: `Marklet-Setup.exe` — 관리자 권한 불필요. WebView2 런타임이 없는 PC 에서는 설치 프로그램이 Microsoft 에서 받아 먼저 설치한다.
SHA-256: `d13d4749138fb09ea0677485fcda9ea96eb03fe0ff6b11b1c416d9694522587f`

## 1.0.12 — 2026-10-07
인쇄 미리보기와 PDF 내보내기를 더하고, 메뉴와 툴팁을 Marklet 모양으로 바꿨다.

**새로운 것**
- **인쇄 미리보기** — `Ctrl+P`. 쪽 썸네일 · 확대/축소 · 인쇄 · 저장이 있는 미리보기 창이 열린다. 어두운 테마여도 밝은 테마로 만들어진다.
- **PDF로 내보내기** — `Ctrl+Shift+P`. 저장 대화상자가 문서가 있는 폴더와 `문서이름.pdf` 로 채워져 열린다.
- PDF 에 **책갈피(목차)** 가 들어간다. PDF 뷰어 왼쪽 패널에서 제목별로 이동할 수 있다.

**바뀐 것**
- 더 보기(⋮) 메뉴와 우클릭 메뉴를 윈도우 기본 모양 대신 Marklet 의 드롭다운으로 바꿨다(반전색 강조, 둥근 모서리). 항목마다 **단축키**를 적었다.
- 컨트롤 버튼의 툴팁도 같은 모양의 알약 + 단축키 칩으로 바꿨다.
- 메뉴는 `↑` `↓` `Home` `End` 로 이동하고 `Esc` 로 닫는다.
- 편집기와 입력칸의 우클릭은 붙여넣기 · 맞춤법 때문에 윈도우 기본 메뉴 그대로다.

**알려진 것**
- 인쇄 미리보기 창은 내장 PDF 뷰어라 항상 어두운 화면이다. 출력된 PDF 자체는 밝은 테마다.
- 인쇄본에 이미지 아래의 "탭하면 크게 보기" 안내 문구가 찍힌다.

**설치**: `Marklet-Setup-1.0.12.exe` — 관리자 권한 불필요, 이전 버전 위에 덮어 설치.
SHA-256: `593f1fd9adb9e1ac3608d4acdc0959ec8a06cc7017218f207e8931736fa62f4b`

## 1.0.11 — 2026-10-07
편집 · `.txt` 보기 · 목차 도크.

**새로운 것**
- **편집** — `Ctrl+E` 로 편집기, `Ctrl+S` 로 저장. 열린 그대로 되돌려 쓴다(인코딩 UTF-8 · BOM · UTF-16 · CP949, 줄바꿈 CRLF/LF 유지).
- 저장하지 않은 편집은 창 제목에 `●`. 닫거나 다른 문서를 열기 전에 묻는다. 편집 중 다른 프로그램이 파일을 바꾸면 저장할 때 덮어쓸지 묻는다.
- **`.txt`** 를 서식 없이 연다(`Ctrl+U` 로 마크다운처럼 보기). 연결 프로그램 목록에만 올라가며 메모장 등 기본 앱은 바뀌지 않는다.
- **목차 도크** — `Ctrl+T` 로 왼쪽에 열리고 지금 읽는 절을 따라간다. 제목이 없는 문서는 안내 창이 뜬다.

**바뀐 것**
- 읽는 화면에서 `Tab` 이 아무것도 순회하지 않는다.

**설치**: `Marklet-Setup-1.0.11.exe`
SHA-256: `db3e1cd64dac7eecb7c9f0a41510ea7dae6f4fea2d66c8748f28f76316e3e7b6`

## 1.0.10 — 2026-10-07
첫 Windows 설치형. `.md` 를 더블클릭하면 그 문서만 보이는 창이 뜬다.

- 표 · Mermaid · 수식 · 코드 하이라이트, 같은 폴더의 그림과 다른 문서 링크
- 마우스를 움직이면 떠오르는 컨트롤(목차 · 찾기 · 테마 · 더 보기), 본문 탭으로 고정/해제
- Alt 메뉴 · 우클릭 · 단축키(`Ctrl+F` 찾기, `Ctrl+T` 목차, `Ctrl+U` 원문)
- 다른 편집기에서 저장하면 자동 갱신, CP949 문서 지원

**설치**: `Marklet-Setup-1.0.10.exe`
SHA-256: `a4579fc7d439efa54d0c8293489f480b7d28d290bcefa2312047477f6fc7bf55`

### 모든 버전 공통

- `.md` 더블클릭이 다른 앱으로 열리면 우클릭 → 연결 프로그램 → Marklet → 항상.
