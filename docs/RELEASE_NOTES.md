# Marklet for Windows — 릴리즈 노트

새 버전은 **맨 위**에 추가한다(최신이 먼저). 각 버전 절은 아래 틀을 따른다.
GitHub 릴리즈 본문에는 해당 버전 절을 그대로 붙여 넣는다.

```
## 1.0.x — YYYY-MM-DD
한 줄 요약.

**새로운 것** / **바뀐 것** / **고친 것** — 해당하는 것만
- 사용자 눈에 보이는 변화 위주. 단축키는 `백틱`으로.

**설치**: `Marklet-Setup-1.0.x.exe` — 관리자 권한 불필요, 이전 버전 위에 덮어 설치.
SHA-256: `…`   (sha256sum Marklet-Setup-1.0.x.exe)
```

공통 안내(코드 서명 없음 · SmartScreen)는 맨 아래 한 번만 적는다.

## 1.0.12 — 2026-10-07
인쇄 미리보기와 PDF 내보내기를 더하고, 메뉴와 툴팁을 Marklet 모양으로 바꿨다.

**새로운 것**
- **인쇄 미리보기** — `Ctrl+P`. 쪽 썸네일 · 확대/축소 · 인쇄 · 저장이 있는 미리보기 창이 열린다. 어두운 테마여도 밝은 테마로 만들어진다.
- **PDF로 내보내기** — `Ctrl+Shift+P`. 저장 대화상자가 문서가 있는 폴더와 `문서이름.pdf` 로 채워져 열린다.
- PDF 에 **책갈피(목차)** 가 들어간다. PDF 뷰어 왼쪽 패널에서 제목별로 이동할 수 있다.

**바뀐 것**
- 더 보기(⋮) 메뉴와 우클릭 메뉴를 윈도우 기본 모양 대신 Marklet 의 드롭다운으로 바꿨다(반전색 강조, 둥근 모서리). 항목마다 **단축키**를 적었다.
- 컨트롤 버튼의 툴팁도 같은 모양의 알약 + 단축키 칩으로 바꿨다.
- 메뉴는 `↑` `↓` `Home` `End` 로 이동하고 `Esc` 로 닫는다.
- 편집기와 입력칸의 우클릭은 붙여넣기 · 맞춤법 때문에 윈도우 기본 메뉴 그대로다.

**알려진 것**
- 인쇄 미리보기 창은 내장 PDF 뷰어라 항상 어두운 화면이다. 출력된 PDF 자체는 밝은 테마다.
- 인쇄본에 이미지 아래의 "탭하면 크게 보기" 안내 문구가 찍힌다.

**설치**: `Marklet-Setup-1.0.12.exe` — 관리자 권한 불필요, 이전 버전 위에 덮어 설치.
SHA-256: `593f1fd9adb9e1ac3608d4acdc0959ec8a06cc7017218f207e8931736fa62f4b`

## 1.0.11 — 2026-10-07
편집 · `.txt` 보기 · 목차 도크.

**새로운 것**
- **편집** — `Ctrl+E` 로 편집기, `Ctrl+S` 로 저장. 열린 그대로 되돌려 쓴다(인코딩 UTF-8 · BOM · UTF-16 · CP949, 줄바꿈 CRLF/LF 유지).
- 저장하지 않은 편집은 창 제목에 `●`. 닫거나 다른 문서를 열기 전에 묻는다. 편집 중 다른 프로그램이 파일을 바꾸면 저장할 때 덮어쓸지 묻는다.
- **`.txt`** 를 서식 없이 연다(`Ctrl+U` 로 마크다운처럼 보기). 연결 프로그램 목록에만 올라가며 메모장 등 기본 앱은 바뀌지 않는다.
- **목차 도크** — `Ctrl+T` 로 왼쪽에 열리고 지금 읽는 절을 따라간다. 제목이 없는 문서는 안내 창이 뜬다.

**바뀐 것**
- 읽는 화면에서 `Tab` 이 아무것도 순회하지 않는다.

**설치**: `Marklet-Setup-1.0.11.exe`
SHA-256: `db3e1cd64dac7eecb7c9f0a41510ea7dae6f4fea2d66c8748f28f76316e3e7b6`

## 1.0.10 — 2026-10-07
첫 Windows 설치형. `.md` 를 더블클릭하면 그 문서만 보이는 창이 뜬다.

- 표 · Mermaid · 수식 · 코드 하이라이트, 같은 폴더의 그림과 다른 문서 링크

- Alt 메뉴 · 우클릭 · 단축키(`Ctrl+F` 찾기, `Ctrl+T` 목차, `Ctrl+U` 원문)
- 다른 편집기에서 저장하면 자동 갱신, CP949 문서 지원

### 모든 버전 공통
- **코드 서명이 없다.** SmartScreen 경고가 뜨면 *추가 정보 → 실행*.
- `.md` 더블클릭이 다른 앱으로 열리면 우클릭 → 연결 프로그램 → Marklet → 항상.
