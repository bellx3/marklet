# 개발자 웹사이트 — 게시용 원본

Play Console 의 **개발자 웹사이트** 칸에 넣을 주소다. 심사에서 실제로 열어 보므로
살아 있어야 한다.

## 왜 만드는가

`https://bellx3.github.io/` 가 **404 다.** 픽셀오아시스 스토어 페이지에 개발자
웹사이트로 등록된 주소인데, 2026-07-31 에도 오늘(2026-08-07)도 404 였다.
`03_출시_절차서.md` 11장 6번이 이미 적어 둔 것이다.

지금 마크릿 쪽 개발자 웹사이트에는 `https://github.com/bellx3/marklet-privacy` 가
들어가 있다. 살아 있기는 하지만 **깃허브 저장소 화면**이라 스토어에서 눌러 온 사람이
보기에 개발자 페이지가 아니다.

주소가 `bellx3.github.io` 루트인 이유: 앱마다 따로 만들 필요 없이 **앞으로 나오는 앱을
전부 여기에 얹는다.** 앱이 늘어도 콘솔에 넣는 주소는 하나다.

## 게시 절차 (10분)

1. GitHub 에서 새 저장소를 만든다. 이름이 **정확히 `bellx3.github.io`** 여야 한다.
   한 글자라도 다르면 사용자 페이지가 아니라 프로젝트 페이지가 되어 주소가 달라진다.
   **Public** 이어야 한다.
2. `index.html` 과 `.nojekyll` 을 저장소 루트에 올린다. (`README.md` 는 올리지 않아도 된다.)
3. Settings → Pages → Source `Deploy from a branch`, Branch `main` / `/ (root)`.
4. 몇 분 뒤 **브라우저로 직접 연다.** https://bellx3.github.io/
   여기서 확인하지 않고 콘솔에 넣었다가 404 로 남은 것이 지금 상황이다.
5. Play Console → 각 앱 → 스토어 등재정보 → **개발자 웹사이트** 를 이 주소로 바꾼다.
   **두 앱 모두** 고친다 (마크릿 · 픽셀오아시스).

> `.nojekyll` 은 빈 파일이면 된다. 없으면 GitHub 가 Jekyll 로 한 번 처리하는데,
> 밑줄로 시작하는 파일을 나중에 더할 때 조용히 빠진다. 지금은 문제가 없지만
> 미리 넣어 두는 편이 싸다.

## 올리기 전에 반드시 채울 것

`index.html` 안의 **【 】** 자리다.

- [ ] `【상호】` — 사업자등록증에 적힌 그대로
- [ ] `【대표자명】`
- [ ] `【000-00-00000】` — 사업자등록번호
- [ ] `【제0000-지역-0000호】` — 통신판매업 신고번호
- [ ] `【사업장 주소】`

> **빈칸을 그대로 공개하지 마라.** 채울 준비가 안 됐으면 `<h2 data-t="bizTitle">` 부터
> 그 아래 `</dl>` 까지 통째로 지우고 올려라. 전자상거래법상 표시 의무가 있으니
> 결국은 채워야 하지만, 【 】 가 박힌 페이지가 스토어에서 열리는 것보다는 낫다.

그리고 링크 두 개:

- [ ] 픽셀오아시스 개인정보처리방침 주소를 문의 항목에 더한다
      (현재 마크릿 것만 걸려 있다. 주소는 픽셀오아시스 콘솔에서 확인할 것)
- [ ] **마크릿이 프로덕션에 올라간 뒤** `<div class="app">` 를
      `<a class="app" href="https://play.google.com/store/apps/details?id=com.marklet.md">`
      로 바꾸고 `테스트 중` 배지를 지운다.
      지금은 그 주소가 **404 다** — 죽은 링크를 미리 걸지 마라.

## ★ 영문 상호는 `Alrimi Studio` 다 (2026-08-10 확정)

**이 표기를 바꾸지 마라.** 로마자 표기법대로면 `알리미` → `Allimi` 지만,
**플레이스토어에 이미 `Alrimi Studio` 로 등록되어 있다.** 표기법보다 이미 나가 있는
이름이 우선이다 — 나중에 맞추려면 스토어 개발자명을 바꿔야 하고 그게 더 크다.

이 이름이 아래 **전부에서 철자·띄어쓰기까지 같아야** 한다. 하나라도 다르면
"검증 불일치"로 막히고, D-U-N-S 는 한 번 등록하면 고치는 데 시간이 걸린다.

| 어디 | 무엇 |
|---|---|
| 홈택스 영문 사업자등록증명 | 영문상호 칸 |
| D-U-N-S 등록 | 사업체명 |
| Google 결제 프로필 | 조직명 (조직 계정 전환 시) |
| 플레이스토어 | 개발자 이름 — **이미 이 값이다** |

★ 개인사업자다. `Inc.` `Co., Ltd.` 를 붙이지 마라 — 그건 법인 표기다.

★ 맞춰야 할 상대는 **결제 프로필의 사업자명**이다. 스토어에 보이는 개발자 이름과
  결제 프로필의 사업자명은 원래 다를 수 있는 값이다. 둘을 같게 두는 편이 단순하다.

한글 상호(`알리미 스튜디오`)는 전자상거래법 표시사항이라 `index.html` 에 그대로 둔다.
법적 표기는 번역하지 않는다.

## 이 페이지가 지키는 약속

푸터에 "이 사이트는 방문자를 추적하지 않습니다"라고 적혀 있다. 그래서:

| 약속 | 어떻게 지키는가 |
|---|---|
| 외부에서 아무것도 안 불러온다 | `<link href>` · `<script src>` · `@import` · `url()` 이 하나도 없다. 확인함 |
| 분석 도구 없음 | 스크립트는 언어 전환뿐이다 |
| 쿠키 없음 | `localStorage` 에 고른 언어만 저장한다. 사생활 보호 모드에서도 죽지 않게 try 로 감쌌다 |

**글꼴을 CDN 에서 불러오는 순간 이 문장이 거짓이 된다.** 예쁘게 고치고 싶어지면
시스템 글꼴 안에서 해라.
